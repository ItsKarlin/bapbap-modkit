# BAPBAP Third Person

Third-person camera. `F1` toggles it. Hides the crosshair, gives you a mouse pointer for card
picks and menus, and exposes FOV, sensitivity, camera height and pitch in
`UserData/BAPBAPThirdPerson.ini` (reloaded live).

Client-side — affects your screen only.

Install by dropping [`dist/BAPBAPThirdPerson.dll`](../../dist/) into `BAPBAP/Mods/`. It is not
part of the modkit installer; once the in-game downloader exists it'll be installable from there.

MIT, clean-room, written against the game's own API.
